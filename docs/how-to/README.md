Each guide gets **one job** done: what you need first, the steps in order, and how to check it
worked. If you are new to the code, the [tutorials](../tutorials/README.md) are the better start.

## Everyday work

- **[Run the tests](run-tests.md)** — the one command CI runs, and how to narrow it.
- **[Add a repository mutation](add-a-mutation.md)** — a new write that syncs, commits
  atomically, can be undone and cancels its alarms.
- **[Localise a string or add a language](localise.md)** — English and German strings, dates,
  counts and quick-add keywords.

## Changing the structure

- **[Add a column to a table](add-a-column.md)** — schema, migration, mappers, backup file,
  sync wire and the Neon mirror, in the order that keeps every install working.
- **[Add a platform port](add-a-platform-port.md)** — when Android and the desktop must do
  something differently.

## Sync, data and releases

- **[Self-host sync](../self-hosting.md)** — point a build at your own Neon project.
- **[Debug sync](debug-sync.md)** — read the app's state, probe the server with curl, reset a
  device.
- **[Import your tasks from Todoist](import-from-todoist.md)** — convert an export into a backup
  file and import it.
- **[Cut a release](cut-a-release.md)** — preview the version, build everything, publish.
