Tutorials take you **from nothing to something working**, one path at a time. Do them in order;
each assumes the one before.

1. **[Build and run Primico in five minutes](quickstart.md)** — clone, launch the desktop app
   from source, run the test suite, install a debug APK.
2. **[A tour of the code, following one task](tour-of-the-code.md)** — type one line into quick
   add and follow it through the parser, the ViewModel, the repository, SQLite, the screen,
   reminders and sync.
3. **[Your first contribution](first-contribution.md)** — add a small derived view, pin it with
   tests, run what CI runs, and open a pull request.

After that, the [how-to guides](../how-to/README.md) cover specific jobs and
[Concepts](../concepts/README.md) explains why things are the way they are.
